# LMS 과제 채점 (제출·첨부 유무 기준)

2026-10-22에 1강을 채점하며 정한 방식이다. 수강생 18명, 과제당 만점 2점.

## 1. 채점 기준

| 상태 | 점수 |
|---|---|
| 미제출 | 0점 |
| 제출했고 첨부파일이 있음(본문 유무와 무관하게 파일이 하나라도 있으면 인정) | 2점 |
| 제출했으나 첨부파일 없이 본문에 링크만 씀 | 0점 (1강에서 사용자가 정한 결정. 박채원·전영준) |

- 과제 안내문(`lecture/chNN.md`의 「과제」절)은 산출물 여러 개와 서술 답안을 요구하지만, 이 기준은 내용 품질을 보지 않는다. 파일이 하나라도 올라왔는지만 본다.
- 링크 제출자(첨부 없이 본문에 링크만 씀)는 0점이다. 1강에서 박채원·전영준을 0점으로 확정했고, 2026-10-23 사용자가 "같은 기준으로 채점"이라고 2~7강 전체에 적용하도록 확정했다. 링크가 열리는지는 따지지 않는다.
- 중간고사 과제(만점 25)는 이 기준의 대상이 아니다.

## 2. 사전 합의 (매번 확인)

- 채점 기준과 저장까지 입력할지를 사용자에게 확인한다. 점수 저장은 학생 성적에 반영되는 작업이다.
- 1강처럼 한 과제를 먼저 저장하고 결과를 확인한 뒤 다음 과제로 넘어간다.

## 3. 브라우저: ego-browser (Chrome 확장 도구 사용 금지)

- **이 스킬은 ego-browser(ego lite)로만 진행한다.** `mcp__claude-in-chrome__*`는 쓰지 않는다. 2026-10-23 사용자 지시로 전환했다.
- 사용 전 `ego-browser skill`로 최신 사용법을 확인한다.
- 사용자가 LMS에 이미 로그인해 두었다. 로그인 정보를 입력하지 않는다.
- 자세한 실행 절차는 아래 「7. ego-browser 절차」를 따른다.
- 스크래치 스크립트는 `.mjs` 파일로 저장해 `ego-browser nodejs < file.mjs`로 실행한다. 프로젝트 폴더에는 두지 않는다.

## 4. 저장 후 확인

- 저장 버튼을 누르면 「저장완료」 알림창이 뜬다. 알림창이 열려 있으면 페이지가 멈춘다. 저장 직후 `page.acceptDialog()`로 닫는다.
- 과제 목록에서 해당 과제의 「채점 현황」이 (채점한 인원)/18로 바뀌었는지 확인한다.
- 한 번 더 저장해 점수를 고칠 수 있다(박채원·전영준을 2점에서 0점으로 바꾼 예).

## 5. 주의

- 「2차 추가」 버튼과 2차 과제 점수는 건드리지 않는다. 화면 안내에 따르면 2차 점수를 주면 1차 점수가 삭제된다.
- 「SMS발송」「쪽지발송」「제출파일일괄다운로드」 등은 사용자 요청 없이 누르지 않는다.
- 값을 지어내지 않는다. 확인하지 못한 학생의 점수는 입력하지 않고 보고한다.

## 7. ego-browser 절차

- 채점 화면은 영문 UI로 바뀌어 있다. 제목은 「assignment name」, 버튼은 「View」「apply」「save」다. 한글 텍스트로 대기하면 시간 초과가 난다.
- 제출물 모달은 iframe 안에 있어 `page.evaluate`로 읽을 수 없다. `page.snapshot()`의 `text "..."` 줄을 파싱한다. 「첨부파일」과 「content」 사이의 `.확장자 NNNByte` 줄을 센다.
- 모달 닫기는 `loc=href:javascript:fncCloseLayer();`로 한다.
- 점수 입력은 `page.fill(selector)` 뒤에 input·change 이벤트를 발생시킨다. 이벤트가 없으면 저장이 반영되지 않았다.
- 저장 버튼 「저장하기」를 누르면 「저장완료」 알림창(JavaScript alert)이 뜬다. 이 알림창이 열린 동안 페이지가 멈춘다. 저장 직후 `page.acceptDialog()`를 호출한다. 1·2강에서 멈췄던 원인이 이것이다.
- 스크립트가 파싱 오류를 내면 heredoc 대신 `.mjs` 파일로 저장해 `ego-browser nodejs < file.mjs`로 실행한다.
- 과제 목록은 주소를 직접 열면 메인으로 돌아간다. 「나의 강의실」→ 강의 카드 → 「Assignment Management」(`a[href="/lms/class/report/prof/doListView.dunet"]`)로 들어간다.
