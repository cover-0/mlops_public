# 중간 미니 프로젝트 — 1~7주차를 본인 데이터로 다시 돌린다

> **8주차 · 중간고사 대체**

□ 중간고사 대신 1~7주차 내용을 묶은 개인 미니 프로젝트를 한다  
  ○ 재택 프로젝트와 현장 검증 두 부분으로 나뉨  
  ○ 재택 프로젝트에서는 학번으로 만든 본인 데이터로 소주제 세 개(B1·B2·B3)를 실행하고 산출물을 냄  
  ○ 현장 검증은 수업 시간 50분 동안 지필로 봄. 코딩 도구와 인터넷 없이, 본인 데이터에서 뽑은 표를 보고 「설정값 하나를 바꾸면 본인 결과가 어떻게 달라지는가」에 답함  

□ 재택 프로젝트에서는 코딩 에이전트(Claude Code·Codex·Copilot 등)를 써도 됨  
  ○ 대신 점수의 대부분은 현장 검증에 있음. 에이전트가 만든 코드를 실행만 하고 규칙을 이해하지 못하면 현장 문항에 답할 수 없음  
  ○ 에이전트를 썼다면 대화 기록을 함께 냄(5절). 기록이 있다는 이유로 감점하지 않음  

## 1. 이 프로젝트에서 확인하는 것

□ 아래 다섯 가지를 본인 데이터의 값으로 설명할 수 있는지 확인함  

| 소주제 | 다루는 주차 | 본인 데이터로 설명할 것 |
|---|---|---|
| B1 침묵 실패 탐지기 | 1~3주 | 프로그램은 종료 코드 0으로 끝났는데 저장하면 안 되는 응답을 어느 검사가 잡는가. 검사 하나를 빼거나 임계를 바꾸면 무엇이 그대로 지나가는가 |
| B2 이벤트 회계 | 4~5주 | 받은 건수 = 중복 + 수용 + 지연 폐기 등식이 본인 데이터에서 성립하는가. watermark 지연 허용을 바꾸면 어느 이벤트의 판정이 바뀌는가 |
| B3 확정 통계와 피처 | 6~7주 | 일 배치의 총계 보존식과 품질 게이트가 어느 날을 막았는가. 막힌 날 다음 날 아침의 훈련 샘플에 시점 조인으로 무엇이 붙는가 |

**표 M.1** 소주제 세 개와 각각에서 설명할 것

## 2. 시작 전 준비

□ 저장소를 최신으로 받고, 학번을 파일에 적음  

```bash
git pull
echo 20231234 > practice/midterm/student_id.txt   # 본인 학번으로 바꾼다
pip install -r practice/midterm/code/requirements.txt
```

□ 학번으로 본인 입력 데이터를 만듦  

```bash
python practice/midterm/code/m-0-make-dataset.py
```

  ○ `practice/midterm/data/input/` 아래에 B1 응답 6개, B2 이벤트 배치 3개, B3 일별 원장 4개와 사전·샘플 파일이 생김  
  ○ 같은 학번이면 몇 번을 돌려도 글자 하나까지 같은 파일이 나옴. 학번이 다르면 측정소 구성, 결함 위치, 이벤트 건수가 다름  
  ○ `manifest.json`에 시드와 파일별 SHA-256이 적힘. 채점할 때 이 파일로 본인 학번 데이터를 썼는지 확인함  

> B1의 측정값은 2주차 실습 입력(2026-06-28 22:00·23:00 서울 실제 응답)에서 측정소 25곳을 골라 그대로 옮긴 것이다. 결함은 그 위에 일부러 심었다. B2·B3의 민원 데이터는 4~7주차와 같은 시뮬레이션이다.

## 3. 소주제와 실행할 파일

| 순서 | 실행할 파일 | 하는 일 | 채울 곳 | 참고할 주차 코드 |
|---|---|---|---|---|
| 0 | `m-0-make-dataset.py` | 학번으로 입력 데이터 생성 | 없음 | — |
| 1 | `m-1-silent-failure-checks.py` | B1 — 응답 6개에 검사 C1~C5, 기준·현재 분포 KS 검정 | `run_checks`, `drift_test` | `1-4-collector-checks.py`, `2-2-drift-visualize.py` |
| 2 | `m-2-event-accounting.py` | B2 — 중복 제거, 10분 창, watermark 5분·15분 두 번 | `run` 안의 TODO 1~5 | `4-3-deduplicate-events.py`, `5-3-watermark-trace.py` |
| 3 | `m-3-batch-feature.py` | B3 — 일 배치 다섯 갈래, 품질 게이트, 재실행 해시, 시점 조인 | `clean_day`, `gate`, `join_samples`의 TODO | `6-3-clean-accounting.py`, `7-4-point-in-time-join.py` |

**표 M.2** 실행 순서와 채울 함수

□ 각 파일 맨 위 설명에 처리 규칙이 번호로 적혀 있음. 규칙을 바꾸지 않음  
  ○ 규칙을 바꾸면 산출물 값이 정답과 달라지고, 현장 문항도 그 규칙을 전제로 냄  
  ○ 반환 딕셔너리의 키 이름을 바꾸지 않음. 채점 스크립트가 그 키를 읽음  

□ 다 채웠으면 실행 증거를 남김  

```bash
python scripts/run_and_capture.py midterm
```

  ○ `practice/midterm/results/`에 파일마다 `.log`와 `.evidence.json`(소스·출력 SHA-256)이 생김  
  ○ 네 파일 모두 `exit_code: 0`이어야 함. 끝까지 못 채웠으면 실패한 그대로 냄 — 실패 로그도 증거임  

## 4. 현장 검증 (수업 시간 50분)

□ 문제지는 학번마다 다름  
  ○ 문제지에 본인 데이터에서 뽑은 표가 인쇄되어 나옴. 표와 각 파일의 처리 규칙만으로 답할 수 있게 냄  
  ○ 코딩 도구·인터넷·휴대전화는 쓰지 않음. 본인 `results/*.log` 인쇄본은 가져와도 됨  

□ 문항은 모두 「설정값 하나를 바꾸면 본인 결과가 어떻게 달라지는가」를 물음. 다음 종류의 판단을 손으로 할 수 있어야 함  
  ○ 검사 임계를 바꾸면 어느 응답의 실패 목록이 바뀌는가  
  ○ watermark 지연 허용을 바꾸면 각 배치의 watermark가 몇 시 몇 분이 되고, 어느 이벤트의 판정이 바뀌는가  
  ○ 품질 게이트 임계를 바꾸면 어느 날이 통과하고, 그 때문에 시점 조인 결과가 어떻게 바뀌는가  
  ○ 보고서 내용이 바뀌면 재실행 해시가 어떻게 되는가  

> 이 판단은 재택 프로젝트에서 규칙을 직접 따라가 본 사람이면 몇 분 안에 끝난다. 코드를 실행만 하고 규칙을 읽지 않았다면 표의 숫자를 어디에 넣어야 하는지부터 막힌다.

## 5. 제출

□ 현장 검증 전날 자정까지 LMS에 압축 파일 하나로 냄  

1. `practice/midterm/data/input/manifest.json`
2. `practice/midterm/data/output/` 폴더 전체 (`b1_checks.json`·`b2_accounting.json`·`b3_report.json`·`b3_reports/`)
3. `practice/midterm/results/` 폴더 전체 (`.log`·`.evidence.json`)
4. `practice/midterm/code/`의 m-1·m-2·m-3 (본인이 채운 파일)
5. 보고서 — 아래 여섯 가지를 각각 세 문장 이내로 씀. 텍스트·PDF 무방
6. 코딩 에이전트를 썼다면 대화 기록(내보내기 파일 또는 화면 갈무리). 쓰지 않았다면 「쓰지 않음」 한 줄

□ 보고서 여섯 가지 — 본인 산출물의 값을 옮겨 적고 씀  

1. (B1) 본인 응답 중 C1~C4는 모두 통과하고 C5만 실패한 파일이 있으면 그 이름을 적고, C5가 없었다면 그 응답이 저장되어 어떤 값이 어떻게 틀어지는지 씀. 없으면 C5를 왜 두는지 1주차 산출물 값으로 씀
2. (B1) 본인 `drift`의 `p_value`·`alpha`·`drift_detected`를 옮겨 적고, 이 결과를 「두 시각의 분포가 같다」로 보고하면 왜 틀리는지 씀
3. (B2) 지연 5분 실행과 15분 실행의 받음·중복·수용·지연 폐기를 나란히 적고, 두 실행에서 등식이 모두 성립함을 산술로 보임
4. (B2) 지연 폐기된 이벤트는 창별 집계 어디에도 나타나지 않음. 운영에서 이 폐기를 무엇으로 감지할지 씀
5. (B3) 품질 게이트에 막힌 날의 다섯 갈래 값과 미매핑률을 옮겨 적고, 그날 보고서 파일이 없다는 것을 무엇으로 확인했는지 씀
6. (B3) `future_leak`이 `true`인 샘플 하나를 골라 시점 조인 값과 최신값을 옮겨 적고, 최신값으로 학습하면 서빙에서 무엇이 어긋나는지 씀

□ 값을 지어내지 않음. 실행이 안 되면 어디서 막혔는지 그대로 씀
